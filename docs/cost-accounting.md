# 《下次做给我吃》成本记录

## 目前能确认什么

六集当前成片合计 403 秒；预热片和宣传片主要复用正片镜头与对白。用户提供的 Musein 截图显示某一时点还剩 7,481 积分，流水中出现过视频单笔扣 86 分、33 分，以及图片单笔扣 11 分。这些是余额和个别交易，不是六集的累计消耗。最初剧本将 7,481 分分配给基础镜头和重试镜头，那是开工预算，也不是事后账单。

制作中确有返工：同一镜头多次生成；第一集重做单手机接听镜头，第二集重做门口站姿和钱段声音，第三集重拍撒葱问句，第五集重做说话人错位的车票问句，第六集补纸条镜头并撤掉重叠机器声。返工消耗了生成额度、筛选和剪辑时间，但现有资料无法逐笔确认这些镜头扣了多少分。

## 为什么现在不能报人民币总额

缺少完整的 Musein 生成流水、充值实付款和当时的积分购买价格。活动赠送积分与现金购买积分也不能直接按一个价格相加。Musein [服务条款](https://musein.cn/terms)将具体收费标准和消耗规则指向购买页面。当前只能确认发生了平台资源消耗，**无法确认本项目实际支付了多少人民币**。

同样，Codex 本地会话计数不是短剧项目的可计费 token 账单，既不能准确划出这部短剧的用量，也不能据此换算人民币。声音工具和本地剪辑还占用了机器及人工时间，但没有工时、电力记录。

## 下次怎样把成本算清楚

开工时给每个镜头编号。每次生成登记：使用的模型和参数、扣点、是否退款、失败原因、成片保留秒数，并保存平台流水；另外记录活动赠分、现金充值、外部服务账单和制作工时。完片后分别汇总：

- **实际现金支出**：充值实付款、外部付费服务和授权费用。
- **平台资源消耗**：本项目逐笔扣点减退款；赠分与购买积分分列。
- **返工成本**：重做镜头的扣点和人工工时。
- **单镜成本**：总扣点除以通过验收并进入成片的镜头数。

本次若要补算，需要 Musein 完整积分流水与充值订单。拿到这两项后，才能把视频生成、图片生成和重复尝试按项目筛出来，再根据实际付款算人民币。
