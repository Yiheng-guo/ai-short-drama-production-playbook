# 《下次做给我吃》项目复盘

## 简短介绍

“我把一条母女早餐广告，扩成六集独立有声短剧，负责故事、镜头设计、生成和验收。制作时碰到人物换脸、双手机、机器声和口型错位，我们按问题镜头重做，并把角色、声音、道具纳入同一套检查。最后交付六集正片、预热片和宣传片。最大的收获是：单个镜头能生成，不代表整部剧就能让观众顺畅看懂。”

## 为什么做这部短剧

参赛短片《离家第一顿》讲女儿搬家后第一次给自己做早餐。它能传达妈妈的牵挂，但没有完整对话，也没有可以连续展开的冲突。我想验证的是：能否用同一份情感关系，做出一部不依赖比赛背景、观众从第一集就能看懂的短剧。

我们面向的是刷竖屏视频、愿意看家庭和生活题材的观众。观众未必先看过参赛片，也不会为了弄懂设定反复回放。因此，每集都必须让人物有明确行动，结尾留下由剧情自然引出的下一步，而不是只靠字幕或“下集见”制造悬念。

## 从故事到成片

故事确定后，我先把六集的因果串起来：女儿知遥离职，接下拍摄早餐店的工作，却在名单里发现妈妈丽珍的店要转让。她以为妈妈遇到经济困难；随着拍摄推进，她才知道妈妈想把店交给徒弟阿禾，自己去看海。知遥也必须向妈妈坦白离职的事。最后，阿禾接店，妈妈出发，母女重新约定下一顿早餐。每集的结尾都接着上一集人物的选择往前走，第六集收束故事。

有了剧情，才进入生产设计。我们固定三位主角的外形、服装和声线，明确公寓与早餐店的空间关系，并记录手机、围裙、鸡蛋、车票等道具在每场的状态。剧本再拆成镜头卡：谁在画面里，谁说哪句话，嘴是否可见，动作从哪里开始、在哪里结束，下一镜怎么接。Musein 用来生成镜头候选；原片下载后编号，用镜头清单选择可用片段，再由本地剪辑流程合成整集。这样发现问题时，可以回到具体镜头和原片，而不用整集推倒重来。

最初我们低估了“连续”有多难。单看一条生成片段可能成立，放到前后镜头里却会露出两部手机、人物换脸、早餐店变样，或者煎蛋位置跳变。声音也一样：有些句子字面正确，听起来却像机器念稿；第五集的“你真去啊？”甚至落到了妈妈的嘴上。我们没有继续用字幕掩盖这些问题，而是重做关键镜头，尽量保留画面里的自然同期声；可见嘴的对白逐句核说话人，重复字则让画面和声音按同一段一起剪。乱码纸条和证明不再承担唯一的剧情信息。

剪辑完成后，我们分三遍验收：先静音看人、道具和动作是否连续，再只听声音判断角色、语气和回应是否自然，最后带声逐镜看口型、电话接听顺序和切点。技术检查能发现坏文件或明显的黑帧，仍需要人眼人耳判断故事是否顺畅。

## 交付与反思

目前完成六集有声正片、一条正片前预热片和一条独立宣传片。预热片来自试看片反馈：直接看第一集，不容易马上弄清女儿接拍和妈妈转店的关系。它帮助新观众进入故事，但也说明首集的信息铺陈还有改进空间。宣传片负责呈现冲突和悬念，与预热片的用途不同。

如果再做一次，我会先制作一场 20–30 秒的双人对话小样，确认人物、声线和口型能够稳定成立，再铺开六集；同时逐镜记录生成次数、扣点、失败原因和最终有效秒数。这样既能控制“抽卡”返工，也能计算每条合格镜头的真实成本。下一步还需要让没有参与制作的人盲看六集，记录他们在哪一集、哪一句开始看不懂，再决定是改正片还是改宣发入口。本项目已经完成制作与本地成片整理，但没有发布后的完播、追更数据，不能把“做出来”说成“市场验证成功”。

制作期的 11,460 积分、按当前套餐约 ¥526 的资源折算与 Token 口径，见[成本核算](cost-accounting.md)；镜头清单、渲染器和分层质检见[技术实现](technical-implementation.md)。

## 可复用的方法

这次返工把一个流程问题暴露得很清楚：角色设定、声音试听和镜头生成不能各自通过验收后就直接拼成整集；在同一场连续戏里，人物身份、道具状态、声源和口型必须一起核对。下一次会先用一段双人对话小样验证最难的声画关系，再扩大到六集。具体镜头卡和逐关检查标准见[制作 SOP](production-sop.md)。
